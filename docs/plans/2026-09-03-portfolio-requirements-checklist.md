# 민희수 포트폴리오 요구사항 체크리스트

이 문서는 2026-09-03 대화에서 확정된 요구사항과 검증 근거를 한곳에서 추적한다.
상태 표시는 `충족`, `진행 중`, `보류`, `미충족`만 사용하며, 최종 완료 전에는
테스트 통과만으로 시각 요구를 `충족`으로 올리지 않는다.
