# Education Side Workstation Revision Design

## Goal

교육 픽셀 장면의 기존 도서관 배경, 후경 컴퓨터, 투명 캐릭터 스프라이트와 능력치 흐름은 보존한다. 캐릭터 주변의 전경 작업대만 캐릭터와 같은 우측 측면 시점으로 다시 그려, 의자에 앉은 캐릭터가 옆모습 노트북을 타이핑하는 장면으로 읽히게 한다. 동시에 창밖 건물 불빛을 여러 위치와 서로 다른 리듬으로 확장하고, 박스형 상태 문구를 정확히 중앙 정렬한다.

## Foreground composition

배경의 정면형 모니터들은 도서관 컴퓨터실의 깊이를 보여 주는 환경 데이터로 유지한다. 전경의 큰 정면 모니터와 긴 카운터만 제거하고, 캐릭터 왼쪽에 얇은 의자 등받이와 좌판, 오른쪽에 짧은 측면 책상과 계단형 노트북 화면·베이스를 배치한다. 캐릭터 기준선과 여덟 포즈는 유지해 프레임 전환 때 머리가 튀지 않게 한다. 타이핑 손은 노트북 키보드에 닿고, 노트 포즈의 페이지는 작업면 위에 남으며, 하체는 책상 앞치마와 의자 좌판 뒤로 자연스럽게 가린다. iPhone에서는 오른쪽 액션 레일을 침범하지 않도록 작업대 우측 끝을 가상 좌표 `center + 50` 이내로 제한한다.

## Skyline lights

건물 하나당 한 개이던 불빛을 높이에 따라 여러 행·열로 늘린다. 창 위치는 고정된 정수 seed로 결정하고, 절반가량은 계속 켜 두며 일부는 꺼진 채 유지하고 나머지만 서로 다른 주기와 위상으로 점멸시킨다. 매 프레임 위치나 밝기를 무작위로 바꾸지 않아 픽셀 윤곽이 흔들리지 않게 한다. 라이트·다크 팔레트에는 켜짐, 약한 켜짐, 꺼짐 색을 각각 제공한다.

## Boxed labels

중앙 정렬 대상은 Education의 `LEARNING`, Career의 `LV + UP!`, Education의 `SESSION COMPLETE` 세 문구다. `// 21C`는 완전히 제거하고 능력치 행의 인라인 `+1`은 현재 위치를 유지한다. 각 painter는 캐시된 `TextPainter`의 실제 전경·1px 그림자 영역을 측정하고, 두 영역의 합집합 중심을 박스 중심에 맞춘 뒤 최종 원점만 정수 픽셀로 반올림한다. 공통 순수 배치 함수를 두 painter가 공유한다.

## Verification

골든 이미지 전체 비교 대신 두 지원 크기의 국소 렌더 픽셀을 검사한다. 측면 노트북 화면과 키보드, 손 접촉, 의자 실루엣, 하체 가림을 확인하고 기존 정면 전경 모니터가 사라졌는지 검증한다. 창 영역은 여러 진행률에서 점등 좌표 합집합·교집합·패턴 수를 검사한다. 세 문구는 정확한 문자열과 합성 텍스트 영역 중심이 박스 중심에서 0.5 논리 픽셀 이내인지 확인한다. 마지막에는 iPhone/iPad 라이트·다크와 타이핑·노트·완료·레벨업 프레임을 캡처해 육안 검수한다.
