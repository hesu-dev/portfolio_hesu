# 모바일 프로필 경력 피드와 Reels 상세 설계

## 변경 목적

모바일·iPad 전용 `ProfileApp`의 첫 버전은 Skills 하이라이트와 프로젝트 갤러리를 다시 보여 줘 전용 Skills·포트폴리오 앱과 정보가 중복됐다. 최신 요구에서는 기존 macOS `AboutApp`에 있던 Career와 Education을 프로필의 핵심 콘텐츠로 삼고, 하단 3열 카드에서 항목을 고르면 Instagram Reels를 닮은 세부 화면으로 이동한다.

기존 데스크톱 About·Skills·포트폴리오 앱과 공용 `PortfolioData`는 변경하지 않는다. 모바일 홈의 독립 `profile` 앱 ID와 첫 아이콘도 유지한다.

## 프로필 루트

프로필 요약에는 공용 데이터의 이름·영문명·headline·biography, GitHub·이메일 액션을 유지한다. 상단 수치는 Profile 안에서 실제로 탐색하는 콘텐츠와 일치하도록 `게시물`, `경력`, `교육`으로 구성한다. 게시물 수는 경력과 교육 항목 수의 합이다.

하단에는 다음 순서의 단일 3열 정사각형 피드를 둔다.

1. `PortfolioData.experiences`의 모든 경력 항목
2. `PortfolioData.education`의 모든 교육 항목

카드는 종류, 짧은 제목, 기간만 보여 주고 전체 설명은 상세 화면에서 제공한다. 스킬 그룹과 프로젝트는 Profile에서 렌더링하지 않으며 각 전용 앱에서만 유지한다. 데이터가 비어 있으면 전체 폭 빈 상태를 표시한다.

## Reels형 상세

Profile은 경력 또는 교육의 타입과 원본 목록 index만 내부 상태로 가진다. 카드를 탭하면 새 앱이나 중첩 창을 열지 않고 같은 `profile-app` 안에서 상세 목적지로 전환한다.

상세는 제공된 Reels 템플릿의 정보 구조를 참고한다.

- 상단에 `Reels` 문맥을 한 번 표시한다.
- 중앙에는 선택 항목의 종류·기간·제목을 표현한 큰 세로형 code-native 그라데이션 비주얼을 둔다.
- 하단 계정 행에는 공용 프로필 avatar와 실제 이름을 사용한다.
- 캡션에는 경력의 역할·회사·기간·설명 또는 교육의 과정·기관·기간을 생략 없이 표시한다.
- 교육 링크가 있으면 상세 캡션 아래에서만 정확한 URI로 연다.
- 모델에 없는 좋아요·팔로워·팔로잉 수, 임의 사용자 사진, 복제 비트맵은 만들지 않는다.

루트와 상세 모두 한 개의 공용 `AppleMobileNavigationHeader`만 사용한다. 루트의 원형 화살표는 앱을 닫고, 상세의 같은 버튼은 Profile 피드로 돌아간다. 상세에서 피드로 돌아왔을 때 루트의 스크롤 위치를 보존한다.

## 반응형·접근성

3열 피드는 중첩 스크롤 없이 `LayoutBuilder + Wrap + AspectRatio(1)`로 구성한다. iPhone과 iPad 모두 같은 3열 규칙을 사용하고, iPad에서는 최대 폭 콘텐츠를 중앙 정렬한다. 루트와 상세에는 각각 하나의 스크롤 영역을 두며 touch·mouse drag를 허용한다.

각 카드는 최소 44px 탭 영역, 버튼 semantics, Enter·Space 활성화를 제공한다. 상세 진입 시 숨겨진 루트가 의미 트리에 남지 않게 화면을 교체하고, 뒤로가기 semantics를 `Back in 프로필`로 전환한다. Light·Dark, iPhone·iPad, 200% 글자 크기에서도 긴 캡션을 자르지 않고 스크롤로 읽게 한다.

## 검증 계약

- Profile 안에 Skills 하이라이트·프로젝트 갤러리와 해당 데이터 문구가 없는지 확인한다.
- `게시물 = 경력 + 교육` 수치와 경력→교육 순서, 3열 정사각형 geometry를 확인한다.
- 경력과 교육 카드를 각각 열어 같은 Reels형 template과 실제 주입 데이터를 확인한다.
- 상세의 공용 뒤로가기 1회는 피드, 루트에서 다음 1회는 홈으로 이동하는지 확인한다.
- 선택 교육 링크가 정확한 URI를 여는지 확인한다.
- 가짜 social metric과 복제 bitmap이 없는지 확인한다.
- 루트·상세를 iPhone/iPad, Light/Dark, 200%, touch/mouse 조합으로 검증한다.
- 기존 macOS About·Skills·포트폴리오 테스트를 회귀 실행한다.
