# Mobile Home Search Implementation Plan

**Goal:** 모바일 홈의 전체 스크롤을 없애고, 하단 검색 카드 또는 아래 방향 제스처로 앱 검색과 Siri 제안 화면을 연다.

**Architecture:** 홈 그리드를 고정된 행으로 배치하고 짧은 화면에서는 아이콘 크기를 조절한다. 기존 Dock 바로 위에 검색 카드를 둔다. Flutter 모달로 검색 화면을 표시하여 홈의 포커스·터치를 차단하고, 앱 선택 시 기존 앱 열기 경로를 사용한다.

**Tech Stack:** 기존 Flutter 위젯, Dart 표준 라이브러리, 기존 앱 목록과 아이콘.

1. 홈 스크롤 제거, 검색 카드 위치, 터치·마우스 진입, 검색·취소·앱 실행을 테스트로 검증한다.
2. `apple_home_grid.dart`에서 고정 그리드를 구현하고 `apple_mobile_shell.dart`에 검색 진입점을 연결한다.
3. `apple_mobile_search.dart`에서 로컬 앱 검색, Siri 제안, 빈 검색 결과와 닫기를 구현한다.
4. 모바일 기존 테스트를 새 홈 동작에 맞추고, 홈·Dock·앱 내부 스크롤 및 라이트·다크 렌더링을 검증한다.

실제 Siri 서비스나 사용자 계정에는 연결하지 않는다. 앱 내부 스크롤과 데스크톱 동작은 유지한다.
