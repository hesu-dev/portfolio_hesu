# 모바일 Instagram형 프로필 앱 설계

## 목표

iPhone과 iPad 홈에서 기존 Notes 프로필 위젯을 제거하고, 첫 번째 위치에 독립적인 `프로필` 앱 아이콘을 배치한다. 아이콘을 열면 Instagram의 정보 구조를 참고한 민희수 포트폴리오 프로필을 표시한다. 기존 macOS `AboutApp`, Notes UI, 데스크톱 런처 구성은 변경하지 않고 재사용 가능하게 보존한다.

## 선택한 접근

새 `PortfolioAppId.profile`과 `ProfileApp`을 만든다. 기존 `about`의 모바일 표시 이름이나 화면을 바꾸는 방식은 데스크톱 About과 결합되어 이후 재사용을 어렵게 하고, 기존 Notes 위젯을 축소하는 방식은 새 아이콘과 독립 화면을 요구한 목적에 맞지 않는다. 별도 앱 식별자는 모바일 런처 순서와 전용 콘텐츠를 명확히 분리하면서 기존 경로를 안정적으로 유지한다.

`profile`은 `portfolioMobileLauncherAppIds`의 첫 항목에만 포함한다. `portfolioLauncherAppIds`와 `portfolioDockAppIds`에는 넣지 않아 macOS 바탕화면과 Dock을 유지한다. `AppleHomeGrid`에서는 `_MobileNotesProfileButton`만 제거하고 앱 그리드가 화면 최상단부터 시작하도록 패딩을 조정한다. Notes 관련 공용 위젯과 `AboutApp` 파일은 삭제하거나 변경하지 않는다.

## 화면 구조와 데이터

`MobileAppSurface`의 공용 뒤로가기·중앙 제목·더보기 헤더를 그대로 사용하고 내부에 중복 헤더를 만들지 않는다. `ProfileApp`은 하나의 세로 스크롤 영역에 다음 내용을 순서대로 표시한다.

1. GitHub 주소에서 파생한 사용자명과 원형 그라데이션 프로필 마크
2. 이름, 영문 이름, headline, biography
3. 프로젝트·스킬·경력 수를 보여주는 세 개의 통계
4. 실제 GitHub와 이메일 주소로 연결되는 두 개의 44px 이상 액션
5. 첫 스킬 그룹을 사용한 원형 하이라이트
6. 전체 프로젝트를 보여주는 Instagram형 3열 정사각형 그리드

사용자 사진이 제공되지 않았으므로 복제 이미지나 임의 사진 대신 코드로 그린 중립적인 프로필 마크를 사용한다. 프로젝트 이미지도 데이터에 없으므로 프로젝트 제목과 기술을 기반으로 한 서로 다른 그라데이션 타일로 표현한다. 모든 텍스트와 링크는 `PortfolioData`에서 읽어 주입 데이터 테스트가 가능하도록 한다.

## 반응형·테마·접근성

iPhone은 화면 폭 전체를 쓰고, iPad는 같은 콘텐츠를 가운데 정렬한 최대 폭 컨테이너로 확장한다. 프로젝트는 양쪽 모두 3열을 유지하되 폭과 간격만 조정한다. 큰 글자에서도 통계와 버튼은 `Wrap`으로 재배치하고 텍스트는 제한된 줄 수 안에서 말줄임한다.

색상은 현재 `AppleTheme`의 surface/label/separator를 기준으로 라이트·다크 팔레트를 나눈다. 프로필 앱 본문은 `CustomScrollView`와 기존 전역 `PortfolioScrollBehavior`를 사용해 터치와 마우스 드래그를 모두 지원한다. 새 아이콘과 버튼에는 명시적인 키, 버튼 의미 정보, 한국어 접근성 라벨을 제공한다.

## 검증

- iPhone/iPad 모바일 카탈로그의 첫 항목이 `profile`이고 Notes 위젯 키가 렌더되지 않는지 확인한다.
- 프로필 탭 시 기존 About이 아니라 `profile-app`이 열리고 공용 헤더로 닫히는지 확인한다.
- 주입한 이름·소개·통계·전체 프로젝트가 렌더되는지 확인한다.
- 라이트·다크, iPhone/iPad, 200% 글자 크기에서 오버플로가 없는지 확인한다.
- 프로필 본문이 터치와 마우스로 스크롤되는지 확인한다.
- macOS 런처와 기존 `AboutApp`/Notes 테스트가 그대로 유지되는지 확인한다.
