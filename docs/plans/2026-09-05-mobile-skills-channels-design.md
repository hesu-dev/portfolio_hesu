# Mobile Skills Channels Design

## 목표

모바일 Skills를 데스크탑·태블릿과 같은 3개 채널 체계로 맞추되, 모바일에서만 채널 목록과 채널 상세을 분리한 2뎁스 경험을 제공한다. 모바일 목록 상단의 카드 영역은 자격증 카드 1개로 유지하며 `정보처리기사`를 표시한다.

## 구조

- `compact: true`인 iPhone 레이아웃만 모바일 목록/상세 상태를 사용한다.
- 데스크탑과 `tablet: true` 레이아웃은 화면 폭과 관계없이 기존 3-pane 채널 화면을 유지한다.
- 모바일 1뎁스는 자격증 카드 1개와 `skillGroups`에서 온 채널 3개만 표시한다. 개별 스킬은 채널로 승격하지 않는다.
- 채널을 선택하면 같은 `SkillsApp` 안에서 2뎁스로 전환한다. 상세의 뒤로가기는 Skills 앱을 닫지 않고 목록으로 돌아간다.
- 데스크탑·태블릿·모바일은 공통 `_SkillChannelHeader`, `_SkillActivityFeed`, `_SkillActivityMessage`를 사용한다. 폼팩터별로 채널 안의 문구나 메시지 UI를 따로 하드코딩하지 않는다.
- 공통 헤더는 `# 채널명`, `1명의 멤버`, `1개의 탭`을 표시한다. 모바일은 같은 헤더에 뒤로가기 버튼만 주입하고 스크롤 영역 밖에 두어 고정한다.
- 공통 본문은 오늘 날짜 구분선과 스킬별 메시지로 구성한다. 각 메시지는 코드 기반 원형 프로필 아바타, 스킬명, 오전 시간, 동일한 활동 설명 본문을 가진다.

## 데이터

`PortfolioData`에 자격증 목록을, `PortfolioSkillGroup`에 스킬별 활동 본문을 선택형 데이터로 추가한다. 런타임 생성자는 입력 컬렉션을 방어 복사하고, 기존 호출부는 기본 빈 컬렉션으로 호환한다. 실제 포트폴리오 데이터에는 자격증 `정보처리기사` 하나와 각 스킬의 활동 설명을 둔다.

오늘 날짜는 `DateTime.now()`를 기본으로 사용하되 `SkillsApp`에서 테스트 시각을 주입할 수 있게 한다. 화면에는 `오늘 · YYYY년 M월 D일`로 표시한다. 실제 인물 사진 자산이 없으므로, 기존 Profile 화면과 일관된 코드 기반 모노그램 아바타를 프로필 사진으로 사용한다.

## 접근성 및 회귀

- 모바일 채널과 뒤로가기는 44px 이상의 버튼 semantics를 가진다.
- 320×480, 200% 글자 크기, Light/Dark에서 목록과 상세가 overflow 없이 스크롤된다.
- 데스크탑·태블릿의 기존 채널 선택과 3-pane 구성을 보존하면서, 세 폼팩터에서 같은 헤더·날짜·프로필·이름·시간·활동 본문을 검증한다.
- 자격증/활동 데이터의 불변성과 검색 텍스트 포함 여부를 단위 테스트한다.
