# Profile Reel Reply and Desktop About Revision Design

## Goal

프로필 경력·교육 상세의 정보 위계를 단순화한다. 픽셀 미디어 위에는 프로필 계정 행과 현재 섹션명인 `경력` 또는 `교육`만 남긴다. 하단 리플에서는 프로필 소유자 이름 대신 각 경력·교육 항목 자체의 제목을 작성자 위치에 배치한다. 데스크톱 About 메모는 섹션명을 한글화하고 연락처 영역을 제거한다.

## Reel overlay

`_ProfileReelOverlay`의 계정 행은 유지한다. 그 아래에는 섹션명 한 줄만 렌더하고, 프로필 headline과 `경력 N개`·`교육 N개` 메타데이터는 제거한다. 프로필 피드 본문에 있는 headline과 정사각형 경력·교육 카드의 개수 표시는 상세 오버레이 바깥이므로 유지한다. 기존 픽셀 미디어, 우측 액션 레일, 높이, 라이트·다크 대비와 접근성 액션은 바꾸지 않는다.

## Shared reply item

새 공개 데이터 모델을 만들지 않고 기존 `_ProfileReplyItem`의 두 팩토리가 공통 표시 슬롯을 구성한다. 경력은 `organization`을 제목 위치에 표시하고 본문은 `period`, `description` 순서로 둔다. `role`은 리플에서 완전히 제외한다. 교육은 경력의 회사명과 같은 소속 주체인 `institution`을 제목 위치에 표시하고 본문은 `period`, `program`, 선택적 링크 순서로 둔다. 프로필 모노그램 아바타와 링크 동작은 유지한다. 같은 제목이 본문에 다시 나타나지 않게 해 정보 중복을 없앤다.

공통 컴포넌트의 패딩과 아바타 크기는 기존 `compact` 규칙을 유지한다. 따라서 iPhone, iPad와 직접 렌더되는 넓은 Profile surface가 같은 데이터 계약과 정렬을 공유한다. 긴 제목은 생략하지 않고 자연스럽게 줄바꿈하며, 확대 글자에서도 가로 넘침이 없어야 한다.

## Desktop About

데스크톱 전용 About 앱의 `Career`와 `Education` 제목을 각각 `경력`, `교육`으로 바꾼다. `Contact` 제목, 부제, 이메일·GitHub 행과 Contact 앞 구분선을 함께 제거하고 사용되지 않는 Contact 전용 위젯도 삭제한다. 모바일과 태블릿은 별도 `ProfileApp`을 사용하므로 이 변경으로 해당 플랫폼의 프로필 UI를 교체하지 않는다. Mail 앱의 별도 Contact 관련 문구와 원본 포트폴리오 데이터는 유지한다.

데스크톱 이력 항목도 모바일·태블릿 리플의 정보 위계를 따른다. 경력은 첫 줄에 `organization`과 `period`를 놓고, 들여쓴 본문에는 `description`만 표시하여 `role`을 제거한다. 교육은 첫 줄에 `institution`과 `period`를 놓고, 들여쓴 본문에 `program`과 선택적 링크·feedback을 유지한다. 제목과 기간은 좁은 창에서 `Wrap`으로 자연스럽게 줄바꿈하고 본문 들여쓰기는 공백 문자가 아니라 패딩과 좌측 구분선으로 표현한다.

## Desktop chrome follow-up

macOS 창 신호등은 시각 툴팁을 표시하지 않되 기존 `Semantics` 이름과 키보드 조작을 유지한다. 세 번째 녹색 버튼에는 일반 상태에서 확대 아이콘, 최대화 상태에서 복원 아이콘을 표시하고 비대화형 장식 상태에도 확대 아이콘을 둔다. 시스템 메뉴의 프로필 동작 문구는 `About This Portfolio` 대신 `민희수 프로필 보기`로 표시하며, 클릭 시 About 창을 여는 기존 동작은 바꾸지 않는다.

## Verification

위젯 테스트에서 두 상세 오버레이의 허용 텍스트와 금지 텍스트를 각각 검증한다. 경력 리플은 회사명만 제목에 있고 역할명이 없으며, 교육 리플은 기관명만 제목에 있고 기간·과정명·링크가 본문에 있는지 확인한다. 이 계약을 iPhone, iPad, 넓은 독립 Profile surface와 확대 글자에서 검사한다. About 테스트는 넓은 창과 좁게 리사이즈한 데스크톱 창 모두 한글 제목을 사용하고 Contact 및 고아 구분선이 없으며, 회사·기관과 기간이 본문보다 위에 놓이고 역할명이 제거되었는지 확인한다. 신호등 테스트는 Tooltip 부재, 확대·복원 아이콘, 기존 semantics·포커스·콜백을 검증한다. 시스템 메뉴 테스트는 새 문구와 기존 About 창 열기 동작을 함께 확인한다. 마지막으로 전체 테스트, 정적 분석, 웹 빌드와 실제 브라우저 화면을 확인한다.
