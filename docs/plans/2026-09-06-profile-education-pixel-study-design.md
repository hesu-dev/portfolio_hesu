# 교육 도트 스터디 애니메이션 설계

## 목표

모바일·태블릿 프로필의 교육 게시물을 열면 경력 상세와 같은 크기의 미디어 슬롯에서, 플레이어 캐릭터가 21세기 도서관 컴퓨터실에서 계속 공부하는 도트 애니메이션을 보여 준다. 첨부된 고전 육성 게임 화면은 따뜻한 실내 공간, 반복 행동, 능력치가 차례로 상승하는 피드백 리듬만 참고하고 이미지나 고유 UI를 복제하지 않는다.

## 시각 구성

장면은 경력 러너와 동일한 144 단위 가상 캔버스를 실제 미디어 슬롯 전체에 균일 확대한다. compact 화면에서는 높이 258px, 일반 화면에서는 288px이며, 화면 높이가 부족할 때는 기존 상세 레이아웃의 제약을 그대로 따른다.

배경과 UI는 `CustomPainter`로 그린다. 배경은 책장, 유리 파티션, 천장 조명, 여러 대의 데스크톱 모니터, 충전 포트와 스탠드 조명을 갖춘 현대적인 도서관 컴퓨터실이다. 전경 책상에 갈색 포니테일과 안경을 유지한 플레이어가 앉고, 캐릭터만 새 투명 RGBA 스프라이트 시트에서 그린다. 픽셀 좌표 스냅, anti-aliasing 비활성화, nearest-neighbor 필터를 사용해 기존 경력 애니메이션과 같은 도트 질감을 유지한다.

능력치 패널은 기존 카메라 버튼, 오른쪽 액션 레일, 하단 계정 설명을 피한 상단 좌측~중앙 안전 영역에 둔다. `FLUTTER`, `DART`, `UX`, `SOLVE` 네 줄이 0.7초 간격으로 한 칸씩 상승하며 활성 행에 색상 강조, 작은 확장 구간, `+1` 팝업을 표시한다. 마지막에는 짧은 `SESSION COMPLETE` 피드백을 보여 준 뒤 화면 단절 없이 다음 학습 사이클을 시작한다.

## 동작 구조

새 `EducationPixelStudy` 위젯은 하나의 결정적 반복 `AnimationController`와 `CustomPainter`를 사용한다. 타임라인은 타이핑, 모니터 읽기, 메모, 눈 깜빡임의 캐릭터 프레임과 모니터 커서, 조명, 능력치 상승을 함께 제어한다. 위젯 빌드는 매 프레임 반복하지 않고 painter의 `repaint`에 controller를 연결한다.

`_ProfileReelOverlay`는 경력 여부 boolean 대신 미디어 종류를 받아 경력에는 기존 `CareerPixelRunner`, 교육에는 `EducationPixelStudy`를 삽입한다. 두 장면은 동일한 `profile-reel-media-slot`을 채우므로 크기 계약과 댓글·좋아요·공유·뒤로가기 흐름은 바뀌지 않는다. 컬러 장면 위 오버레이 액션은 라이트·다크 모드 모두 흰색으로 유지한다.

## 접근성·성능·검증

장면 전체는 변화하는 수치를 매번 읽지 않는 단일 이미지 semantics로 설명한다. `MediaQuery.disableAnimationsOf`가 켜지면 controller를 중지하고 학습과 능력치가 함께 보이는 결정적 정지 프레임을 제공한다. 이미지와 controller는 명시적으로 해제하며, 스프라이트 로딩 실패는 Flutter 오류 보고 후 코드로 그린 배경과 UI를 계속 표시한다.

위젯 테스트는 교육 전용 장면 삽입, 경력과 동일한 rect, 시간에 따른 실제 픽셀 변화, 능력치 순서, reduced-motion 정지, 단일 이미지 semantics, 라이트·다크 및 작은 화면 회귀를 검증한다. 최종 단계에서 전체 테스트, 정적 분석, 웹 빌드와 실제 렌더 스크린샷을 확인한다.
