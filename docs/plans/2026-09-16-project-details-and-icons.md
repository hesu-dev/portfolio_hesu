# Project details and app icons

**Goal:** 프로젝트 소개 안에 링크를 포함하고 기술, 역할·기여도, 회고를 읽기 쉽게 정리한다. 네 개의 출시 앱에는 공식 스토어 아이콘을 사용한다.

**Architecture:** 기존 Finder 탐색과 프로젝트 데이터 모델을 유지한다. 기존 highlights를 역할·기여도 문구에 재사용하고 회고 enum에 배운 점, 직무 연관성, 성과·지표를 추가한다. 아이콘은 로컬 에셋으로 번들링하고 없는 프로젝트는 기존 폴더를 사용한다.

**Tech stack:** Flutter / Dart, 기존 위젯 테스트.

1. `projects_finder_app_test.dart`에서 소개 안의 링크, 정보 순서 및 아이콘 대체를 확인한다.
2. `projects_app.dart`에 소개를 추가하고 역할·기여도 카드를 기술 다음으로 이동한다. 링크 비활성화와 피드백은 유지한다.
3. `portfolio_data.dart`에 프로젝트별 역할 및 배움·직무 연관성·성과를 채운다. 사용자가 임시 작성을 허용했으며 가상 기여율·지표에는 임시 예시임을 명시한다.
4. 공식 아이콘 4개와 출처를 저장하고 기존 Finder 타일 및 상세 헤더에 표시한다. 상세 헤더의 연도 배지는 제거하며 지정 아이콘이 없으면 빈 라운드 사각형을 표시한다.
5. 관련 프로젝트/데이터/반응형 테스트와 `flutter analyze`를 실행하고 로컬 브라우저에서 확인한다.

별도 탭·편집 UI·의존성은 추가하지 않는다. 데스크톱과 모바일은 동일한 상세 컴포넌트를 사용한다.

## 추가 요청: GitHub 프로필과 외부 링크 안내

- GitHub 프로필 카드는 `hesu-dev/hesu-dev`의 공개 README를 번들 에셋으로 렌더링한다. Markdown 렌더링은 검증된 Flutter 패키지를 사용한다.
- 기존 저장소 이름과 URL을 기본 데이터에서 제거하고 `hesu-dev`, `sukenell`, `sunelll` 계정 카드 세 개를 표시한다. 각 계정의 실제 GitHub 아바타와 표시 이름을 사용한다.
- 상단의 중복 프로필 열기 버튼과 README의 배포 계정 안내는 표시하지 않는다. 외부 프로필은 하단 계정 카드에서 연다.
- Projects, About, GitHub, Mail의 외부 링크 성공 시 피드백을 남기지 않는다. 실패 안내와 비동기 요청 순서 보호는 유지한다.
- README와 계정 링크, 성공 안내 제거를 기존 앱 동작 테스트로 검증하고 브라우저에서 확인한다.

## 추가 요청: 링크 버튼과 프로필 벡터 일러스트

- 프로젝트 링크를 스토어별 아이콘·이름·이동 화살표가 있는 라운드 버튼으로 바꾼다. 기존 링크 열기 및 요청 중 비활성화는 유지한다.
- 프로필 피드의 경력·교육 미리보기에 각각 업무·학습 장면의 정사각형 플랫 SVG를 적용한다.
- 프로필, 게시글, 댓글의 MH를 하나의 공통 SVG 인물 아바타로 교체한다.
- 게시글 하트·댓글·공유 영역의 세로 배경과 버튼 배경을 투명하게 표시한다. 픽셀 애니메이션은 유지한다.
- 기존 반응형·접근성·상호작용 테스트와 로컬 브라우저에서 표시 결과를 확인한다.

### 일러스트 후속 조정

- 경력은 모니터를 보는 측면 얼굴로 맞추고, 왼쪽 포니테일·좁은 몸통·모니터 받침대를 유지한다.
- 교육의 안경을 귀와 콧등에 연결하고 책·손·책상이 자연스럽게 닿도록 수정한다.
- 공통 프로필 아바타는 활짝 웃는 표정, 낮은 포니테일, 크림색 칼라의 로즈색 블라우스로 변경한다.

## 추가 요청: AI 역량 검사 프로젝트

- 회사 목록에 `AI 역량 검사`를 추가하고 기간은 `2026.08 - 2026.09`로 표시한다. 사용자가 확인한 기획·디자인·구성·개발 전체 담당과 기여도 100%를 반영한다.
- 로컬 원본 프로젝트에서 확인한 기술과 기능만 소개에 쓰고 제공된 POC URL을 연결한다. 지정한 앱 아이콘이 없으므로 일반 폴더와 빈 상세 헤더 사각형을 사용한다.
- 원본의 실습·개인 리포트·결과 관리 스크린샷 세 장을 번들링한다. 원본 비율을 유지하고 누르면 전체 화면에서 확대할 수 있게 한다.
- 회사 목록의 첫 번째에 표시한다. 데이터, 폴더 줄바꿈, 모바일 확대·닫기 동작을 검증한다.

## 추가 요청: AI Switch와 회사 폴더 순서

- 회사 폴더는 `AI 역량 검사`, `AI Switch`, `Blue Mentor`, `IRIS`, `AI-Bver`, `HiddenTag` 순서로 표시한다.
- `AI Switch`는 React·TypeScript 홈페이지 유지보수 업무와 제공된 사이트 링크를 담은 기본 항목으로 추가한다.
- 미정인 기간은 빈 값으로 두고 상세 화면의 기간 배지는 표시하지 않는다. 지정 아이콘이 없어 빈 상세 헤더 사각형을 사용한다.
- 기존 폴더 탐색·링크 동작 테스트를 새 순서에 맞추고 전체 테스트 및 로컬 화면을 확인한다.
