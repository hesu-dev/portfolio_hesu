# Architecture diagram glyphs

These four glyphs are extracted from the embedded SVG images in the existing
`assets/github-profile/mysql.svg`, `php.svg`, `unity.svg`, and `typescript.svg`
badges. The surrounding badge rectangles and text are omitted, and each glyph
has a solid fill for legibility on the light and dark diagram canvases.

Original badge source records remain in `assets/github-profile/sources.json`.
Product names and logos identify the technologies used in each project.
